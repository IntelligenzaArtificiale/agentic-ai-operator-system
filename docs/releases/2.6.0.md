# Agentic AI Operator System 2.6.0

## Dashboard operativa

- Elenco processi con ricerca, reparto, stato, priorità e paginazione.
- Ultimo esito datato, storico recente, tempi verificati e passaggi più lenti.
- Schede accessibili da tastiera; comandi copiabili senza esecuzione automatica.
- DNA aziendale e configurazione separati dal lavoro quotidiano.
- Dati aggiornati senza shell; icona Desktop per aprire il pannello senza console.
- Nessuna dipendenza grafica o font remoti. Layout verificato anche a 320 px.

## Correttezza e affidabilità

- Le run sono ordinate per data, non per nome del file. Quelle senza data non
  determinano l’ultimo esito. Successi non verificati restano non verificati.
- La media globale è pesata sui campioni, non sulle medie delle procedure.
- Un piano illeggibile non nasconde il processo. I file non validi sono segnalati.
- La dashboard applica la licenza anche a HEAD e API, limita le risorse servite
  ed esclude Host estranei. I contenuti di procedura vengono trattati come testo.
- L’installer non ferma più tutti gli eseguibili sotto `.local/bin`.
- Il runtime usa Python 3.12 e versioni fissate delle dipendenze collaudate,
  anche quando viene installato tramite il wheel di riserva.
- La disattivazione conserva lo stato in caso di errore di rete, per riprovare a
  liberare il dispositivo. Un’installazione senza licenza restituisce successo
  quando il setup è riuscito, distinguendo l’attivazione ancora necessaria.

## Verifiche della release

- 74 test Python superati; 2 moduli d’integrazione esclusi da quella suite e
  verificati separatamente sul runtime Windows installato.
- Trasporto MCP con licenza assente: strumenti elencati e azioni bloccate.
- Cinque comandi MCP reali senza finestra console; timeout preservato.
- Test browser isolato: filtri, paginazione, tastiera, dettagli, copia, XSS,
  stati vuoto e senza licenza; larghezze 320, 375, 414, 768 e 1440 px.
- Contrasto testo minimo misurato 5,96:1; test telemetria PowerShell superato.
- Installazione completa del pacchetto su Windows, anche da un percorso con
  spazi, con dipendenze fissate. Nessuna finestra di attivazione automatica.

## Confini operativi

Il pannello non è uno scheduler autonomo: non invia messaggi, non esegue processi
e non promette attività H24 senza una sessione operativa e un avvio autorizzato.
Il motore e le skill esistenti restano generici; nessuna regola legata a Gmail,
a un gestionale o a una singola azienda è stata aggiunta.

Il pannello licenze PHP non cambia. Per una reinstallazione pulita, disattivare
prima il dispositivo oppure rimuoverne l’associazione dal pannello: eliminare
l’identità locale senza liberare il posto può consumare un secondo slot.
