# Agentic AI Operator System 2.5.2

- Attivazione manuale dall'icona Desktop: installer e dashboard non aprono più
  finestre automaticamente. Il registratore mostra solo l'indicazione di attivare.
- Una sola finestra di attivazione per utente/sessione; richieste in background
  e pulsanti disabilitati mentre una verifica è in corso. Nessun popup di successo.
- Stato licenza e inizializzazione dispositivo serializzati tra processi nella
  stessa sessione Windows. Verifica dei dati salvati prima di confermare
  l'attivazione; eliminata una scrittura ridondante dopo l'attivazione.
- Gli errori locali di accesso allo stato non vengono più presentati genericamente
  come chiave mancante. Nessuna accettazione di licenze scadute o firme non valide.
- La durata della concessione offline non è più mostrata come scadenza contrattuale.
- Istruzioni aggiornate: installazione → icona Desktop → conferma manuale → verifica
  dello stato → riavvio. Messaggio amministrativo con chiave separata dal prompt.
- Benchmark esplorativi reali su Blocco note, Antigravity e Google Sheets:
  Windows MCP mantenuto come motore principale; nessuna migrazione indiscriminata.

## Aggiornamento

Installare lo ZIP 2.5.2 dalla release ufficiale. Una licenza valida già salvata
non viene cancellata né richiede una nuova chiave. Durante l'aggiornamento gli
strumenti possono richiedere il riavvio di ChatGPT/Codex.

Per il pannello PHP aggiornare soltanto `templates/admin.php` e aggiungere
`src/DeliveryMessage.php`. Non sovrascrivere configurazione, chiavi server,
`license.json` o altri dati privati. Non servono migrazioni del database.
Il helper usa sintassi compatibile con PHP 7.4. Il test locale usa PHP 8.4:
non equivale a una prova sull'hosting PHP 7.4 dell'utente.

Non è stata riprodotta una nuova attivazione reale sul computer del padre:
i test automatici usano chiavi generate per la prova e cartelle temporanee.
