# Agentic AI Operator System 2.5.3

Elimina le console dei comandi interni durante l'uso del sistema.

- PowerShell interno al MCP e al procedure runner avviato con CREATE_NO_WINDOW.
  Anche i comandi di pulizia dopo timeout usano la modalità senza console.
- Adattamento limitato al modulo PowerShell di Windows MCP 0.8.5: nessuna modifica
  globale a subprocess e nessuna soppressione delle applicazioni aperte dall'utente.
- Controlli Python/Codex della dashboard eseguiti senza console, con output ed
  errori acquisiti e timeout. Non vengono nascosti gli errori all'agente.
- Corretto il quoting dei percorsi con spazi nell'avvio del server dashboard.
  Una risposta 403 del server già avviato non provoca un altro avvio.

Non è possibile controllare le finestre aperte da programmi esterni o da comandi
esplicitamente interattivi. La modifica riguarda i processi di servizio di AIOS;
non nasconde browser, editor, richieste di licenza o terminali richiesti dall'utente.

Aggiornamento senza modifiche alle procedure o ai dati di licenza. Riavviare
ChatGPT/Codex per ricaricare i server MCP già in memoria. Nessun aggiornamento
del pannello PHP richiesto per questa correzione.

Verifiche: 54 test Python passati (2 saltati nell'ambiente di sviluppo), cinque
invocazioni reali di PowerShell tramite il runtime MCP con handle console zero,
timeout del processo preservato, argomenti con spazi/virgolette e codici di errore
conservati. Dashboard installata rigenerata tramite avvio senza console, exit code
zero, licenza esistente ancora attiva. Il test separato del trasporto MCP verifica
che l'adattamento non rimuova il blocco per licenza assente.
