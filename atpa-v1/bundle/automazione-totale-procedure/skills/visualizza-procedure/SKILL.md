# Visualizza procedure

Esegui `%LOCALAPPDATA%\Programs\Intelligenza Artificiale Italia\Automazione Totale Procedure Aziendali\Update-Dashboard.ps1 -Open` con PowerShell. Lo script controlla MCP, plugin, registratore e catalogo, rigenera i dati e apre il dashboard locale.

Se lo script non esiste, segnala che l'installazione deve essere riparata. Non ricostruire manualmente il dashboard e non usare Windows-MCP per navigare nella pagina salvo richiesta dell'utente.
